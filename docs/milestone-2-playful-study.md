## PART A — Playful bright world (frontend redesign, Apollo)
Keep Appu centered + static; keep the pop-up-around-Appu lesson layout and high readability. Change the *world and feel*:
- **Palette:** move off the dark boardroom. Bright, warm base (soft cream/sky light surfaces) with vibrant playful accents — keep brand cyan + gold, add cheerful coral/green/purple. Maintain strong text contrast (light theme done right; keep the theme tokens so a dark variant still exists).
- **Stage/background:** replace the dark keynote auditorium behind Appu with a bright, friendly learning environment (cheerful classroom / soft space-adventure / sunny scene) — light and colorful, Appu clearly the guide in front. Prefer a code-drawn/gradient scene or a light asset; keep it FIXED (user dislikes changing backdrops).
- **UI shapes:** big rounded "chunky" pill buttons, rounded playful cards, generous spacing, friendly rounded display font for headings (load from Google Fonts CDN e.g. Fredoka/Baloo 2 with a rounded system fallback stack; body stays highly legible).
- **Delight:** cheerful micro-animations, confetti/star burst on success, bouncy button feedback, friendly iconography. Respect `prefers-reduced-motion`.
- **Gamification scaffolding:** visible XP/stars, a streak, a progress bar, badges, level-up moment. Persist per-user later (localStorage first, backend subscription/profile later).
- **Lesson content restyle (playful):** colorful diagram nodes with icons, fun numbered step chips, sticker-style analogy callout, quiz styled as a game with celebration. Keep "no bordered box" free-standing pop-ups + auto-vanish.
- **Keep:** Appu static + centered, mic/dock, quick-action chips, responsive phone + TV, all Milestone-1 invariants.

## PART B — NotebookLM-style study suite (phased)
Core idea: APPU becomes a source-grounded study *tool* for CBSE kids, not just Q&A. Reuse what exists (NCERT tool, lesson-card brain, ElevenLabs voice, concept-map).

**Study Actions bar** — after any Appu answer, offer playful buttons, each generated by the (cloned) brain in our lesson-card/structured format:
- **Quiz me** — multi-question quiz; each item has "explain why" + NCERT citation on wrong answers. (extends the quick-check)
- **Flashcards** — flip cards + simple spaced repetition; tap "explain" for detail.
- **Study Guide** — structured chapter summary (key points, definitions, must-knows).
- **Mind Map** — reuse/upgrade the concept-map, playful styling.
- **Appu Podcast (Audio Overview)** — brain writes a friendly spoken walkthrough (optionally 2-voice); played via existing ElevenLabs TTS. Big wow, low new infra.
- **Grounding/citations** — answers cite the child's NCERT chapter ("From Class 8 Science, Ch.1").
- **Upload your material** — kid/parent uploads a chapter PDF / notes / (later) a link → Appu teaches *from that*. Needs backend: storage + embeddings + retrieval (RAG). The one real backend lift.
- **Video Overview** — deferred (heaviest).
